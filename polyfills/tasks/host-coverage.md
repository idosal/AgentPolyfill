## Local models and the recordings

Pi 1.6.0, T3 Code 0.1.12 through its Pi provider, Hermes 0.23.4, OpenCode terminal 2.4.1 and Copilot CLI 1.0.115 each returned a test reply from the installed Ollama model `qwen3.5:2b-q4_K_M` in disposable profiles. T3 needed the model listed in the Pi provider’s custom models. Each host reached the local model without a hosted account.

The README recordings used a scripted local model to choose tools consistently. The running hosts displayed their own approvals and inputs, and the sample MCP servers produced the results. The edits shorten idle waits before a completion wake.
