  │ Quant  │  File size    │   RAM     │                                Fit on 16 GB                                │
  │        │     (7B)      │  needed   │                                                                            │
  ├────────┼───────────────┼───────────┼────────────────────────────────────────────────────────────────────────────┤
  │ Q4_K_M │ ~4.1 GB       │ ~7 GB     │ Comfortable. Leaves room for longer context and your other apps            │

  ├────────┼───────────────┼───────────┼────────────────────────────────────────────────────────────────────────────┤
  │ Q6_K   │ ~5.5 GB       │ ~9 GB     │ Works, but tight if you have a browser or IDE open                         │
  ├────────┼───────────────┼───────────┼────────────────────────────────────────────────────────────────────────────┤
  │ Q8_0   │ ~7.0 GB       │ ~11 GB    │ Not recommended. macOS lets the GPU use only about 2/3 to 3/4 of unified   │
  │        │               │           │ memory                                                                     │
  └────────┴───────────────┴───────────┴────────────────────────────────────────────────────────────────────────────┘

  Avoid Q3 and Q2 on a 7B model. They lose noticeably more quality, and you don't need the savings.

  If the model's Hugging Face page (https://huggingface.co/<repo>?local-app=llama.cpp) marks a quant as compatible, or
  uses its own label such as UD-Q4_K_M, go with that.

  Commands

  # Install (Homebrew builds include Metal GPU support)
  brew install llama.cpp

  # Interactive chat, downloading straight from the Hub
  llama-cli -hf <repo>:Q4_K_M -ngl 99 -c 8192

  # Or as a local OpenAI-compatible server on http://localhost:8080
  llama-server -hf <repo>:Q4_K_M -ngl 99 -c 8192

  Replace <repo> with a GGUF repo, for example bartowski/Qwen2.5-7B-Instruct-GGUF (I didn't check that repo's file list
  live).

  - -ngl 99 puts all layers on the Apple GPU through Metal.
  - -c 8192 sets the context length. Raising it uses more memory, so lower it to 4096 if you run short.
  - Exact filename: if a repo names its files in a way -hf repo:QUANT doesn't recognize, use --hf-repo <repo> --hf-file
    <exact-file>.gguf instead.
  - Gated models: for Llama and similar, run hf auth login first.

  To test the server:

  curl http://localhost:8080/v1/chat/completions -H "Content-Type: application/json" \
    -d '{"messages":[{"role":"user","content":"Hello"}]}'
