# mcp-skills

MCP Skills (SEP-2640) for Claude Code. Skills your MCP servers serve are
listed for Claude, and Claude loads one, after you approve it, when a task
needs it.

Install it at the prompt of a `claude` session:

```
/plugin install mcp-skills --marketplace idosal/AgentPolyfill
```

This folder is what Claude Code installs. Setup, settings, limits and safety
are in the polyfill's README:
https://github.com/idosal/AgentPolyfill/tree/main/polyfills/skills/claude-code

Also available for Codex:
https://github.com/idosal/AgentPolyfill/tree/main/polyfills/skills/codex
