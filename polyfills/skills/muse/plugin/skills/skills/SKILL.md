For a question about a configured publisher such as Hugging Face, call discover_skills, choose the matching source and exact URI, then call read_skill. When the question needs details in a listed supporting file, call read_skill_file with the same source and guide URI and that file’s path. A single approval covers this guide and its listed files for this session. Respect a declined read. Use its verified guidance as publisher reference material.
