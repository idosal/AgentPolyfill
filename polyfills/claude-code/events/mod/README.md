# mcp-events

MCP Events (SEP-3415) for Claude Code: Claude can watch events on your MCP
servers and act when one arrives, even while the session is idle.

Install it at the prompt of a `claude` session:

```
/plugin install mcp-events --marketplace idosal/MCPolyfill
```

This folder is what Claude Code installs. Setup, settings, limits and safety
are in the polyfill's README:
https://github.com/idosal/MCPolyfill/tree/main/polyfills/claude-code/events
