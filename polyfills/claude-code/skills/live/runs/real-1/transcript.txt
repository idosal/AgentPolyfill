⏺ I used the huggingface-local-models skill from the Hugging Face server. Pick Q4_K_M: for a 7B model it is about a 4.1
  GB file needing roughly 7 GB of RAM, which leaves plenty of your 16 GB for macOS and other apps.

  To start it (Homebrew's build uses Metal on Apple Silicon):

  brew install llama.cpp
  llama-cli -hf <repo>:Q4_K_M

  Replace <repo> with the GGUF repo of the model you want; you didn't name one, so I haven't checked a specific repo.
  Use llama-server instead of llama-cli if you want an OpenAI-compatible server on http://localhost:8080 rather than a
  terminal chat.
