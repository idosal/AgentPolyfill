# mcp-skills

MCP Skills (SEP-2640) for Claude Code: skills served by your MCP servers are
listed for Claude and loaded, after your approval, when a task needs one.

Install it at the prompt of a `claude` session:

```
/plugin install mcp-skills --marketplace idosal/AgentPolyfill
```

This folder is what Claude Code installs. Setup, settings, limits and safety
are in the polyfill's README:
https://github.com/idosal/AgentPolyfill/tree/main/polyfills/claude-code/skills
